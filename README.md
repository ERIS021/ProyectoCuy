# MyCuy 🐹

**Software para la producción y crianza del cuy**

## Descripción

MyCuy es una aplicación desarrollada en **C# con Windows Forms** como proyecto final del primer semestre universitario.

El objetivo del sistema es apoyar la gestión de la **producción y crianza de cuyes**, organizando información relacionada con su cuidado, reproducción, producción y uso gastronómico.

La aplicación cuenta con un sistema de **registro y autenticación de usuarios**, además de varios módulos que permiten organizar la información en diferentes áreas relacionadas con la actividad.

## Módulos del sistema

El sistema está dividido en los siguientes módulos:

* **Crianza y Reproducción**
  Gestión de información relacionada con la reproducción y desarrollo de los cuyes.

* **Sanidad y Cuidado**
  Registro de aspectos relacionados con el cuidado y salud de los animales.

* **Producción y Comercialización**
  Información relacionada con la producción y posible comercialización.

* **Gastronomía**
  Apartado relacionado con el uso gastronómico del cuy.
